# Security Policy

Pingway's code is public so anyone can check that it is safe. Thank you for helping keep its users protected.

## Reporting a problem
**Please do not open a public GitHub issue for security problems.**

Report it privately to the developer (River Zola) through the [Pingway support server](https://discord.gg/DDdV48X4G2) on Discord, or with GitHub's **"Report a vulnerability"** button on the Security tab of this repository (if enabled).

Please include what you found, where (file/command), and how to reproduce it. You'll get an answer as soon as possible.

## Rules
- Only test against your **own** copy of the code, never the live Pingway bot, website, database or other users' data.
- No spamming, denial-of-service, or social engineering.

## What this repository does not contain
No bot token, database password, API keys or user data are ever stored in this repository. They live only in the private configuration of the running bot.
