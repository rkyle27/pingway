Pingway
    A modern, open-source Discord bot built for precise personal timing, reminders, and custom event tracking.

✨ Features
    Per-User Anchor Timers: Every user gets their own isolated countdown and celebration timestamp stored securely in a database.
    Smart DM Notifications: Automatically targets and delivers direct messages to users the exact moment their personal timer hits zero.
    Isolated Multi-User Support: Built with scalability in mind—multiple users can run separate, independent timers simultaneously without interference.
    Lightweight & Fast: Built using Discord.js and optimized for smooth background scheduling loops.
